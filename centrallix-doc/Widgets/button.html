button

type: widget/button

visual: yes

container: no

form element: no

Overview:

Combines the functionality of the textbutton and imagebutton, as well as adding the ability to have both text and image displayed in a button. The deprecated widget/textbutton and widget/imagebutton names are rendered by this widget.

Usage:

A Button can be placed inside any visible container, but only nonvisual widgets can be placed within it. Properties that don't apply to the button's type are ignored.

Properties:

Property Type Description
bgcolor string A color, RGB or named, to be used as the button's background.If neither bgcolor nor background are specified, the button is transparent.
align string Sets the alignment of text in the button, can have left right or center (default).
background string A background image for the button.
border_color string A color that outlines the button.
border_radius integer A radius that describes the sharpness of the corners of the button (smaller means sharper).
border_style string Determines the look of the outline. One of 'outset' (default), 'solid', or 'none'. An image-only button defaults to 'none', and one that draws no border also draws no padding, so it hugs its image; a button with text always reserves room for its frame whatever the style.
clickimage string The ObjectSystem pathname of the image to be shown when the user clicks the button. Defaults to 'pointimage' if not specified, which in turn defaults to 'image'.
disable_color string A color, RGB or named, to be used for the button's text when it is disabled.
disabledimage string The ObjectSystem pathname of the image to be shown when the button is disabled. Defaults to 'image' if not specified.
enabled yes/no or expr Whether the button is enabled (can be clicked). Default is 'yes'. Also supports dynamic runclient() expressions allowing the enabled status of the button to follow the value of an expression.
fgcolor1 string A color, RGB or named, for the text on the button. Default "white".
fgcolor2 string A color, RGB or named, for the text's 1-pixel drop-shadow. Default "black".
height integer Height, in pixels, of the text button.
image string The pathname of the image to be shown when the button is "idle".
image_height integer Defines the height of image. Defaults to the button's own height for an image-only button.
image_margin integer Deprecated spelling of 'spacing'.
image_position string Describes where an image sits relative to the text (top, right, bottom, left). Deprecated: use the matching 'type' value instead. Only consulted when 'type' is absent.
image_width integer Defines the width of image. Defaults to the button's own width for an image-only button.
pointimage string The pathname of the image to be shown when the button is pointed-to. Defaults to the 'image' if not specified.
spacing integer The margin around the image, in pixels, which separates it from the text. Defaults to 0. Spelled 'image_margin' on the deprecated widget/textbutton.
repeat yes/no Whether to keep firing the MouseDown event while the user holds the button down. The Click event still fires once, on release.
text string The text to appear on the button.
tooltip string The text that appears when the cursor hovers over the button.
tristate yes/no Whether or not the button is tri-state (does not display a raised border until the user points at it). Default is yes.
type string There are currently 7 different types: 1) text 2) image 3) topimage (image above text) 4) rightimage 5) leftimage 6) bottomimage 7) textoverimage (text over image background).
width integer The width, in pixels, of the text button.
x integer X-coordinate of the upper left corner of the button, relative to its container.
y integer Y-coordinate of the upper left corner of the button, relative to its container.

Actions:

Action Description
SetText Called from a connector, this action sets the button's text to the value passed in through connector's "Text" parameter.
Click Triggers a Click event on the button with the "from_action" parameter set to 1.
Disable This action causes the button to enter its disabled state, displaying the disable_color, if specified.
Enable This action causes the button to enter its enabled state, possibly changing its normal colors.

Events:

Event Description
Click This event occurs when the user clicks the mouse pointer (equivalent to a MouseDown followed immediately by a MouseUp on the same widget) while it is over this widget.
MouseDown This event occurs when the user presses the mouse button on the widget. This differs from the 'Click' event in that the user must actually press and release the mouse button on the widget for a Click event to fire, whereas simply pressing the mouse button down will cause the MouseDown event to fire.
MouseMove This event occurs when the user moves the mouse pointer while it is over the widget. The event will repeatedly fire each time the pointer moves.
MouseOver This event occurs when the user first moves the mouse pointer over the widget. It will not occur again until the user moves the mouse off of the widget and then back over it again.
MouseOut This event occurs when the user moves the mouse pointer off of the widget.
MouseUp This event occurs when the user releases the mouse button on the widget.

Client Properties:

Property Type Description
enabled yes/no Whether the button is enabled. Can be read and set at runtime.
text string Write-only. Setting it is equivalent to invoking the SetText action; reading it always yields an empty string.
